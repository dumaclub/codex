### Assistant

`MultiShot`은 일반적인 범위 스킬이라기보다 “주 대상 + 보조 대상들에게 각각 투사체를 날리는 스킬”로 구현되어 있어서 `UseAttackSkill` 단계에서 보조 타겟을 미리 잡습니다.

핵심 이유는 2가지입니다.

1. 공격 시작 패킷에 보조 타겟 목록이 필요합니다.  
   `BehaviorAttackState.OnBegin()`에서 바로 `MakeAttackBattleAction`을 호출하는데, 여기서 `_behavior.targetMultiList`를 `AttackBattleAction.multiTargetList`에 실어 보냅니다.  
   [BehaviorAttackState.cs](E:/Rasalas/Trunk/qa/Server/EgonServer/ServerNodes/GameNode/FSM/BehaviorStates/BehaviorAttackState.cs:75)  
   [ActorModel.cs](E:/Rasalas/Trunk/qa/Server/EgonServer/ServerNodes/GameNode/Models/Actor/ActorModel.cs:1290)  
   [ActionModel.cs](E:/Rasalas/Trunk/qa/Server/EgonServer/ServerNodes/GameNode/Models/Action/ActionModel.cs:72)

2. 투사체 생성 시점에도 같은 보조 타겟 목록을 사용합니다.  
   `ProcessAttackRange`에서 주 대상에게 투사체를 하나 만들고, `_behavior.targetMultiList`를 돌면서 보조 대상들에게도 투사체를 추가합니다.  
   [ActorModel_Skill.cs](E:/Rasalas/Trunk/qa/Server/EgonServer/ServerNodes/GameNode/Models/Actor/ActorModel_Skill.cs:2285)

   ```csharp
   _behavior.targetActor.AddProjectileAction(projectileAction);

   for (int i = 0; i < _behavior.targetMultiList.Count; i++)
   {
       _behavior.targetMultiList[i].AddProjectileAction(multiProjectileAction);
   }
   ```

즉 `MultiShot`에서 `UseAttackSkill` 안의 처리는 “데미지 적용”이라기보다 “이번 공격에서 같이 쏠 보조 타겟을 예약”하는 성격입니다.

현재 코드 흐름은 이렇게 됩니다.

```text
UseAttackSkill
-> MultiShot이면 CalMultiTarget으로 보조 타겟 선정
-> _behavior.SetMultiTarget(targets)
-> Attack 상태 진입
-> MakeAttackBattleAction에서 multiTargetList 패킷 전송
-> 액션 프레임에서 ProcessAttackRange 실행
-> 주 대상 + 보조 대상에게 각각 ProjectileAction 생성
-> 투사체 충돌 시 DamageFrameEvent
```

`CalMultiTarget`도 보면 주 대상 중심 반경으로 대상을 찾고, `ApplyNumberCount - 1` 만큼만 보조 대상을 뽑습니다. 주 대상은 이미 `targetActor`로 잡혀 있기 때문입니다.  
[BehaviorModel.cs](E:/Rasalas/Trunk/qa/Server/EgonServer/ServerNodes/GameNode/Models/Behavior/BehaviorModel.cs:821)

반대로 `Multi_Target`은 이런 구조가 아닙니다. `Multi_Target`은 투사체 보조 타겟을 미리 예약하는 타입이 아니라, 액션 프레임이 실행될 때 액션 스크립트의 `ScopeType`, `ScopeRange`와 `SkillBaseData.ApplyNumberCount` 기준으로 대상을 찾는 쪽입니다.

그래서 더블 쓰로우_A `<그랜드 마스터>` 같은 스킬은 `MultiShot`처럼 `UseAttackSkill`에서 `targetMultiList`를 미리 채우면 의도와 달라질 수 있습니다. 이 스킬은 “여러 발을 미리 찍어서 날리는 스킬”이 아니라 “프레임 공격 범위 내에서 최대 2명에게 적용되는 스킬”로 보는 게 맞습니다.

정리하면:

```text
MultiShot
= 사용 시점에 보조 타겟 확정
= AttackBattleAction.multiTargetList 필요
= 투사체를 대상별로 생성해야 함

Multi_Target
= 프레임 이벤트 시점에 범위로 대상 판정
= 액션 스크립트 Scope + ApplyNumberCount 기반
= UseAttackSkill에서 보조 타겟 선점하면 안 맞음
```
