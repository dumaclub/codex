네, 원인은 거의 확실히 “DB에서 못 읽음”이라기보다 **DB에서 읽은 뒤 `Clone()/Copy()` 과정에서 `endDate`가 빠진 것**으로 보입니다.

`ServerMoveDBController.SelectByDB()`가 DB entity를 그대로 리스트에 넣지 않고 `entity.Clone()`을 넣습니다. 그런데 `BMUserEntity.Copy()`, `BMCharacterEntity.Copy()`, `BMAccountEntity.Copy()` 안에서 기존 코드는 `idx`, `uId`, `regDate`만 복사하고 `endDate`를 직접 복사하지 않았습니다. `base.Copy(info)`는 `bmStoreId`, `buyCount`, `lastRefreshDate` 쪽만 처리할 가능성이 높아서 `endDate`가 `DateTime.MinValue`로 남은 겁니다.

추가하신 이 코드는 맞는 방향입니다.

```csharp
[DataMember]
[ProtoMember(7)]
public override DateTime endDate { get; set; }
```

단, 이것만으로는 부족할 수 있고, 각 `Copy()`에 아래도 꼭 들어가야 합니다.

```csharp
this.endDate = info.endDate;
```

```csharp
public virtual void Copy(BMUserEntity info)
```
