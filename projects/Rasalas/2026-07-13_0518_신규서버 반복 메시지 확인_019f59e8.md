- Gateway가 캐릭터 요약 로드를 위해 `CS_ZMQ_UserCharacterSummary`를 `Database`로 보내려 함
- 대상은 `targetServerGroupId:100`, `serverId:1003`
- 그런데 `serverStatusInfo is null`이라 전송 실패

핵심 로그:

```text
GetOptimalServerInfo passed, serverStatusInfo is null, serverId: 1003, targetServerGroupId:100
cant found server, targetType: Database, targetServerGroupId: 100, gameDbId: 0, packet:CS_ZMQ_UserCharacterSummary
```

코드상 `RegistLoadingLogin()`은 서버그룹별 캐릭터 목록을 DB 노드에 요청합니다. 820은 `server_group(100).groupInfo`에 들어 있으므로 월드 번호가 100으로 변환되고, 그래서 Gateway는 `server_info`의 `KR_Database01(server_id=1003, type=5, groupId=100)`로 보내야 합니다. 그런데 Gateway가 1003의 `SC_ZMQ_ServerStatus`를 받은 적이 없어 실패합니다.

확인/조치할 것:

1. `KR_Database01` 서버 프로세스가 실제로 떠 있는지 확인
2. Gateway 로그에 `serverId:1003` 상태 수신 또는 `Connected server. fromServerId: 1003 ... Open` 로그가 있는지 확인
3. `KR_Database01`의 `zmqIp/zmqPort`가 Gateway에서 접근 가능한 값인지 확인
4. `server_info` 변경 후에는 `ServerGroupDataReload`만으로는 부족합니다. 이 리로드는 `server_group`만 갱신하므로, `server_info` 추가/수정 후에는 관련 서버들을 재시작해야 합니다.
5. `databaseinfo`의 820 행은 DB 연결 정보일 뿐, Gateway가 직접 붙는 ZMQ 서버가 아닙니다. Gateway의 첫 대상은 여전히 `KR_Database01(1003)`입니다.

즉 지금 접속 실패의 1차 원인은 **Database01 미기동 또는 Gateway-Database01 상태/ZMQ 연결 불량**입니다. 1003이 Open 상태로 잡힌 뒤에야 820 캐릭터 목록/서버 선택 단계로 넘어갈 수 있습니다.
