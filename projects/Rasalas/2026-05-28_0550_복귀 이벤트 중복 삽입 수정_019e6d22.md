```csharp
    // 오늘 출석 처리가 가능하도록 updateDate는 어제로
    eventData.SetUpdateDate(now.AddDays(-1));
    eventData.SetCheckDate(now);
}
```

핵심은 `clearCountList`를 검사하기 전에 reset해야 한다는 점입니다. 이전 회차 보상 대기값이 남아 있으면 현재 코드의 이 부분에서 바로 return 됩니다.

```csharp
if (eventData.clearCountList.Count > 0) { return; }
```

정리하면, 월별 이벤트는 `_userEventDic`에 정상적으로 올라오는 구조이므로 별도 대기 딕셔너리보다 **`CheckAttendAll()`에서 현재 회차 시작 여부를 보고 기존 row를 초기화**하는 방식이 가장 깔끔합니다.
