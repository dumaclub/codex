## 라살라스 권장 방향

라살라스의 신규 타입은 단순히 경험치만 다른 것이 아니라 다음 요소까지 독립될 가능성이 큽니다.

- 일반 9등급, 마스터 16등급
- 마스터 전용 숙련도 코인
- 타입별 포인트와 최대 경험치
- 타입별 프리셋 또는 현재 패널
- 타입별 성장판 및 빙고 상태

따라서 이런 값들을 모두 독립 관리한다면 아스텔리아 방식보다 타입별 2행이 구조적으로 적합합니다.

```text
uId  classType  masteryType  masteryExp  masteryLv
100  Knight     1            ...         9
100  Knight     2            ...         16
```

필요한 스키마 변경의 기본 형태는 다음과 같습니다.

```sql
ALTER TABLE class_mastery_exp
    ADD COLUMN masteryType INT(11) NOT NULL DEFAULT 1
    AFTER classType,
    ADD KEY index_uid_mastery_type (uId, masteryType);
```

- 서버 메모리 Dictionary
- 경험치 패킷 식별
- 서버 이전 및 서버 통합 병합
- 클래스 체인지
- 클라이언트 경험치 캐시

기존 행은 모두 `masteryType=1`로 유지하고, 타입 2 행은 신규 콘텐츠 진입 시점이나 최초 경험치 지급 시 생성하는 방식이 안전합니다.

- 진행도와 프리셋까지 모두 독립 → 타입별 2행
- 경험치만 독립하고 포인트·코인·프리셋은 모두 공유 → 아스텔리아처럼 1행 다중 컬럼

## `AddClassMasteryExp()`를 타입별로 분리해야 하는가?

결론적으로 **데이터와 규칙은 타입별로 분리하되, 함수 자체는 현재처럼 하나를 유지하는 것이 좋습니다.**

```csharp
public long AddClassMasteryExp(
    long uId,
    eCharacterClass classType,
    eMasteryType masteryType,
    long addCount)
```

이 함수 형태는 이미 타입을 명시적으로 전달받기 때문에 적합합니다. 다음처럼 함수를 두 개로 복제할 필요는 없습니다.

```csharp

AddMasterMasteryExp(...);
```

두 함수로 분리하면 DB 접근, 최대 경험치 계산, 초과 경험치 처리, 상태 변경 로직이 중복됩니다.

대신 공통 함수 내부에서 타입별 규칙을 조회해야 합니다.

### 현재 코드의 문제

### 권장 함수 흐름

```csharp
public long AddClassMasteryExp(
    long uId,
    eCharacterClass classType,
    eMasteryType masteryType,
    long addCount)
{
    if (addCount <= 0)
        return 0;

    if (masteryType != eMasteryType.NORMAL_MASTERY &&
        masteryType != eMasteryType.MASTER_MASTERY)
    {
        return 0;
    }

    var cmExp = GetExp(
        classType,
        masteryType,
        uId);

    if (cmExp == null)
        return 0;

    var loader = DataManager.Get<LoaderClassMasteryData>();

    var maxLevel = loader.GetMaxMasteryLevel(
        (int)classType,
        (int)masteryType);

    var maxExp = loader.GetMaxClassMasteryExp(
        masteryType,
        maxLevel);

    var totalExp = cmExp.masteryExp + addCount;
    var appliedExp = Math.Min(totalExp, maxExp) - cmExp.masteryExp;
    var addPoint = Math.Max(0, totalExp - maxExp);

    cmExp.AddMasteryExp(appliedExp, addPoint);

    if (addPoint <= 0)
        return 0;

    var coinRate = loader.GetMasteryCoinPointRate(masteryType);
    if (coinRate <= 0)
        return 0;

    var addCoin = cmExp.masteryPoint / coinRate;

    if (addCoin > 0)
    {
        cmExp.SubMasteryPoint(coinRate * addCoin);
    }

    return addCoin;
}
```

### 1. 사냥 경험치 변환 함수

```csharp
public bool AddClassMasteryExpByHunting(
    eMasteryType masteryType,
    long huntingExp)
{
#if DEBUG_SEA || RELEASE_SEA
    if (DataManager.Get<LoaderUIConfig>()
        .isDisableContent(eMenuType.Mastery))
    {
        return false;
    }
#endif

    if (huntingExp <= 0)
        return false;

    var configId = masteryType switch
    {
        eMasteryType.NORMAL_MASTERY => "MasteryType1ChangeExp",
        eMasteryType.MASTER_MASTERY => "MasteryType2ChangeExp",
        _ => null,
    };

    if (configId == null)
        return false;

    var convertRate = DataManager
        .Get<LoaderClassMasteryData>()
        .GetClassMasteryConfig(configId);

    if (convertRate <= 0)
        return false;

    var convertExp = (long)(huntingExp * convertRate * 0.0001);

    if (convertExp <= 0)
        return false;

    AddClassMasteryExp(
        uId,
        CharacterBaseTable.CharacterClass,
        masteryType,
        convertExp);

    return true;
}
```

## DB 마이그레이션 주의

추가하신 SQL에는 기본값이 없습니다.

```sql
ALTER TABLE equip_set_option
ADD COLUMN spClassMasterySet TINYINT NOT NULL;
```

기존 사용자 행이 `0`으로 생성될 수 있으므로 다음 형태를 권장합니다.

```sql
ALTER TABLE equip_set_option
ADD COLUMN spClassMasterySet TINYINT NOT NULL DEFAULT 1;
```

이미 컬럼을 추가했다면 다음을 적용해야 합니다.

```sql
UPDATE equip_set_option
SET spClassMasterySet = 1
WHERE spClassMasterySet < 1;

ALTER TABLE equip_set_option
MODIFY COLUMN spClassMasterySet TINYINT NOT NULL DEFAULT 1;
```

```csharp
public eMasterySlotColor GetRandomSlotColor(eMasteryType masteryType)
{
    var loader = DataManager.Get<LoaderClassMasteryData>();

    if (!loader.TryGetSlotColorRate(
            masteryType,
            out var totalRate,
            out var rateDic))
    {
        SLogManager.Instance.ErrorLog(
            $"ClassMastery slot color rate is invalid. masteryType:{masteryType}");

        return eMasterySlotColor.None;
    }

    var randomValue = RandomManager.Instance.GetNextValue(1, totalRate);

    foreach (var item in rateDic)
    {
        if (item.Value >= randomValue)
            return item.Key;

        randomValue -= item.Value;
    }

    return eMasterySlotColor.None;
}
```
