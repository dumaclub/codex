## `GetExp()`에 추가로 수정해야 할 오류

현재 수정된 `GetExp()`에는 내부 타입 키가 없을 때 예외가 발생할 수 있는 문제가 있습니다.

```csharp
public ClassMasteryExpEntity GetExp(
    eCharacterClass classType,
    eMasteryType masteryType,
    long uId)
{
    if (_classMasteryExpDic.ContainsKey(classType) == false)
    {
        SetClassMasteryExpEntity(uId, classType, masteryType, null);
    }

    return _classMasteryExpDic[classType][(int)masteryType];
}
```

예를 들어 `NORMAL_MASTERY`가 먼저 등록되어 클래스 Dictionary는 존재하지만 `MASTER_MASTERY`가 아직 없다면, 바깥쪽 조건을 통과한 후 마지막 줄에서 `KeyNotFoundException`이 발생합니다.

클래스 키와 타입 키를 모두 확인해야 합니다.

```csharp
public ClassMasteryExpEntity GetExp(
    eCharacterClass classType,
    eMasteryType masteryType,
    long uId)
{
    if (masteryType != eMasteryType.NORMAL_MASTERY &&
        masteryType != eMasteryType.MASTER_MASTERY)
    {
        return null;
    }

    if (!_classMasteryExpDic.TryGetValue(classType, out var masteryExpDic) ||
        !masteryExpDic.TryGetValue((int)masteryType, out var cmExp))
    {
        SetClassMasteryExpEntity(
            uId,
            classType,
            masteryType,
            null);

        if (!_classMasteryExpDic.TryGetValue(classType, out masteryExpDic) ||
            !masteryExpDic.TryGetValue((int)masteryType, out cmExp))
        {
            return null;
        }
    }

    return cmExp;
}
```

## 1. 경험치·레벨·포인트·코인 분리 여부

네 가지 모두 분리하는 것을 권장합니다.

### 경험치와 레벨

반드시 분리해야 합니다.

- 일반 최대 레벨: 9
- 마스터 최대 레벨: 16
- 타입별 필요 경험치가 다를 수 있음
- 사냥 경험치 반영 비율도 타입별로 다를 수 있음

현재 적용 중인 타입별 `ClassMasteryExpEntity` 2행 구조가 적합합니다.

### 포인트

포인트도 분리하는 것이 맞습니다.

현재 포인트는 최대 경험치를 초과한 경험치를 코인으로 변환하기 위한 중간값 역할을 합니다. 일반과 마스터의 최대 레벨과 경험치 비율이 다르므로 공유하면 다음 문제가 발생합니다.

- 일반에서 획득한 초과 경험치가 마스터 코인으로 바뀔 수 있음
- 마스터에서 획득한 초과 경험치가 일반 코인으로 바뀔 수 있음
- 타입별 코인 변환 비율을 적용하기 어려움

따라서 각 타입 행의 `masteryPoint`를 독립적으로 사용해야 합니다.

### 코인

코인도 분리해야 합니다.

다만 현재 `masteryCoin` DB 필드와 실제 인벤토리 아이템 코인을 구분해야 합니다. 현재 서버는 코인 생성 시 `MasteryCoin` 설정값으로 아이템을 지급하고 있습니다.

### 권장 함수 흐름

```csharp
public long AddClassMasteryExp(
    long uId,
    eCharacterClass classType,
    eMasteryType masteryType,
    long addCount)
{
    if (addCount <= 0)
        return 0;

    if (masteryType != eMasteryType.NORMAL_MASTERY &&
        masteryType != eMasteryType.MASTER_MASTERY)
    {
        return 0;
    }

    var cmExp = GetExp(
        classType,
        masteryType,
        uId);

    if (cmExp == null)
        return 0;

    var loader = DataManager.Get<LoaderClassMasteryData>();

    var maxLevel = loader.GetMaxMasteryLevel(
        (int)classType,
        (int)masteryType);

    var maxExp = loader.GetMaxClassMasteryExp(
        masteryType,
        maxLevel);

    var totalExp = cmExp.masteryExp + addCount;
    var appliedExp = Math.Min(totalExp, maxExp) - cmExp.masteryExp;
    var addPoint = Math.Max(0, totalExp - maxExp);

    cmExp.AddMasteryExp(appliedExp, addPoint);

    if (addPoint <= 0)
        return 0;

    var coinRate = loader.GetMasteryCoinPointRate(masteryType);
    if (coinRate <= 0)
        return 0;

    var addCoin = cmExp.masteryPoint / coinRate;

    if (addCoin > 0)
    {
        cmExp.SubMasteryPoint(coinRate * addCoin);
    }

    return addCoin;
}
```

```csharp
public bool AddClassMasteryExpByHunting(
    eMasteryType masteryType,
    long huntingExp)
{
#if DEBUG_SEA || RELEASE_SEA
    if (DataManager.Get<LoaderUIConfig>()
        .isDisableContent(eMenuType.Mastery))
    {
        return false;
    }
#endif

    if (huntingExp <= 0)
        return false;

    var configId = masteryType switch
    {
        eMasteryType.NORMAL_MASTERY => "MasteryType1ChangeExp",
        eMasteryType.MASTER_MASTERY => "MasteryType2ChangeExp",
        _ => null,
    };

    if (configId == null)
        return false;

    var convertRate = DataManager
        .Get<LoaderClassMasteryData>()
        .GetClassMasteryConfig(configId);

    if (convertRate <= 0)
        return false;

    var convertExp = (long)(huntingExp * convertRate * 0.0001);

    if (convertExp <= 0)
        return false;

    AddClassMasteryExp(
        uId,
        CharacterBaseTable.CharacterClass,
        masteryType,
        convertExp);

    return true;
}
```

두 번째 함수는 사냥·아이템·치트가 공통으로 사용하는 최종 반영 함수로 유지합니다.

역할은 다음으로 한정합니다.

```csharp
public override long AddClassMasteryExp(
    long uId,
    eCharacterClass classType,
    eMasteryType masteryType,
    long addExp)
{
    if (addExp <= 0)
        return 0;

    if (masteryType != eMasteryType.NORMAL_MASTERY &&
        masteryType != eMasteryType.MASTER_MASTERY)
    {
        return 0;

        uId,
        classType,
        masteryType,
        addExp);

        masteryType,
        addCoin);

    var loader = DataManager.Get<LoaderClassMasteryData>();
    var maxLevel = loader.GetMaxMasteryLevel(
        (int)classType,
        (int)masteryType);

    for (var i = 0; i < maxLevel; i++)
    {
        var upgraded = CheckClassMasteryUpgrade(
            GetcmNowStatPanel(),
            classType,
            masteryType);

        if (!upgraded)
            break;

    return addCoin;
```
