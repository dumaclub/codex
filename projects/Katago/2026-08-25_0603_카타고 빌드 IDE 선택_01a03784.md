### 모델 이름 읽는 법

예를 들어:

```text
kata1-b28c512nbt-s13255194368-d5935380940.bin.gz
```

대략 다음 의미입니다.

- `kata1`: 공개 분산학습 프로젝트 이름
- `b28`: 네트워크 블록 수 28
- `c512`: 내부 채널 너비 512
- `nbt`: Nested Bottleneck 구조
- `s...`, `d...`: 학습 진행량과 학습 데이터 시점을 구분하는 번호
- `.bin.gz`: KataGo C++ 실행 파일에서 직접 읽는 모델

대체로 `b`와 `c`가 클수록 강하지만 GPU 메모리 사용량과 계산량도 증가합니다.
