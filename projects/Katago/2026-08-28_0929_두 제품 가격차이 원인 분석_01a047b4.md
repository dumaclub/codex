네, **가장 가까운 설정은 `solid_reactive`**입니다.

1. EVO80을 **USB 유선 모드**로 연결합니다.
2. VIA에서 EVO80 JSON을 불러오고 기기를 인증합니다.

5. `Effect` 드롭다운에서 다음을 선택합니다.

```text
solid_reactive
```

6. 원하는 `Color`, `Brightness`, `Effect Speed`를 조절합니다.
7. 로고까지 꺼두려면 **LOGO RGB → Effect → none**으로 설정합니다.
8. USB를 분리하기 전에 몇 번 눌러 동작을 확인하세요. 설정은 저장된 뒤 2.4GHz/블루투스에서도 적용됩니다.

EVO80 VIA 정의에는 다음 반응형 효과가 포함되어 있습니다. [EVO80 VIA JSON](https://cdn.shopify.com/s/files/1/0835/9706/6540/files/EVO80_0924.JSON?v=1727727415)

- `solid_reactive`: 누른 키 중심
- `solid_reactive_wide`: 주변 키까지 넓게 반응
- `solid_reactive_cross`: 가로·세로 방향으로 반응
- `solid_reactive_nexus`: 누른 지점에서 십자형으로 퍼짐
- `splash`: 물결처럼 퍼짐

다만 `solid_reactive`에서 평소에도 모든 키가 희미하게 켜진다면, **정확히 누른 키 하나만 켜졌다가 완전히 꺼지는 `SOLID_REACTIVE_SIMPLE` 효과는 현재 EVO80 JSON에 노출되어 있지 않습니다.** 이 경우 VIA 설정만으로 완벽한 “키 하나만 점등”은 불가능하고, 가장 가까운 대안은 `solid_reactive` 또는 `solid_reactive_wide`입니다. QMK에서도 `SOLID_REACTIVE_SIMPLE`과 `SOLID_REACTIVE`는 서로 다른 효과로 정의됩니다. [QMK RGB Matrix 문서](https://docs.qmk.fm/features/rgb_matrix)

이 기능만을 위해 출처가 불확실한 펌웨어를 업데이트하는 것은 권하지 않습니다. 우선 `solid_reactive`를 적용해 보시고, 평상시 다른 키까지 켜지는지 확인하는 것이 안전합니다.

### User

알려주신 설정대로 하니 잘 됩니다. 기본적인 RGB 는 꺼진 상태에서 누를때만 표시되도록 할 수 있나요?

### Assistant

지금 보이는 기본 점등과 키 입력 점등을 별도로 0으로 만들 수 있는지 확인해 보겠습니다. EVO80의 효과 목록에는 `SOLID_REACTIVE_SIMPLE`이 빠져 있어서, 다른 반응형 효과나 색상 조합으로 가능한지가 핵심입니다.

### Assistant

정확히 **기본 조명은 꺼지고 누른 키 하나만 켜졌다가 사라지는 효과**는 EVO80 기본 펌웨어/VIA 설정에서는 제공되지 않습니다.

대신 가장 가까운 설정은 다음입니다.

1. **Lighting → PER-KEY RGB**
2. `Effect`를 아래처럼 변경합니다.

```text
solid_reactive_wide
```

3. `Effect Speed`를 높여 빠르게 사라지도록 조절합니다.
4. **LOGO RGB → Effect → none**으로 로고도 끕니다.

`solid_reactive_wide`는 평소에는 어둡고, 누른 키와 가까운 주변 키가 잠깐 켜집니다. `solid_reactive`처럼 모든 키가 기본색으로 켜진 상태는 아닙니다.

누른 키 **하나만** 점등하려면 QMK의 `SOLID_REACTIVE_SIMPLE` 효과가 필요하지만, 현재 EVO80 VIA JSON에는 이 효과가 빠져 있습니다. [EVO80 VIA JSON](https://cdn.shopify.com/s/files/1/0835/9706/6540/files/EVO80_0924.JSON?v=1727727415), [QMK 효과 설명](https://docs.qmk.fm/features/rgb_matrix)

주의할 점:

- RGB 자체를 `OFF`로 만들거나 밝기를 0으로 설정하면 반응형 조명도 함께 꺼집니다.
- JSON에 이름만 `solid_reactive_simple`을 추가해도 펌웨어가 해당 효과를 지원하지 않으므로 작동하지 않습니다.
- 완전한 단일 키 점등을 구현하려면 `ENABLE_RGB_MATRIX_SOLID_REACTIVE_SIMPLE`이 포함된 커스텀 펌웨어가 필요하지만, EVO80은 무선 제어 코드가 포함돼 있어 직접 펌웨어를 수정·플래시하는 것은 권하지 않습니다.

따라서 별도 펌웨어 작업 없이 사용할 수 있는 최선의 선택은 **`solid_reactive_wide` + 로고 RGB 끄기**입니다.

### User

via 에서 배터리 %로 확인할 수 있나요?

### Assistant

EVO80 JSON에는 `BAT`라는 배터리 조회 키코드가 있지만, 이것이 VIA 화면에 숫자로 표시되는 기능인지 키보드 LED로 알려주는 기능인지 구분해야 합니다. 공식 매뉴얼의 표시 방식을 확인하겠습니다.

### Assistant

아니요. **EVO80의 VIA 화면에서는 정확한 배터리 잔량(예: 73%)을 확인할 수 없습니다.** 대신 LED 색상으로 대략적인 구간을 확인합니다.

`Fn + D`를 길게 누르면 Esc 키의 색으로 표시됩니다.

- 빨강: 0~10%
- 노랑: 10~50%
- 파랑: 50~80%
- 초록: 80~100%
- 충전 중: Esc 흰색 점멸
- 충전 완료: Esc 초록색 고정

VIA에서 별도 키로 지정하는 것도 가능합니다.

1. 원하는 레이어와 키를 선택합니다.
2. 키코드 목록에서 `BAT` 또는 `QK_BAT`를 찾습니다.
3. 해당 키에 지정합니다.
4. 지정한 키를 누르면 Esc LED 색으로 잔량 구간이 표시됩니다.

EVO80용 VIA JSON에도 `BAT – Querying Battery Status` 키코드가 포함되어 있습니다. 다만 이것도 **숫자 퍼센트가 아니라 LED 색상 조회 기능**입니다. 이미 F13은 계산기로 사용 중이므로, `Fn` 레이어의 잘 사용하지 않는 키에 `BAT`를 넣는 것이 좋습니다.
