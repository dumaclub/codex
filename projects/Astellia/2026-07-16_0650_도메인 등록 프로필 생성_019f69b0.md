### Assistant

이미지 기준으로는 도메인 구매 전에 Tencent Cloud 콘솔에서 **등록자 프로필(Registrant Profile)** 과 **이메일·휴대폰 인증**을 먼저 완료해야 합니다. 실제 계정 정보와 인증번호가 필요하므로, 인프라팀에는 해당 작업을 요청하는 형태로 등록하면 됩니다. 최신 공식 절차도 함께 확인하겠습니다.

### Assistant

인프라팀 작업등록에는 아래처럼 요청하시면 됩니다. 회사 도메인이라면 **Organization(법인)** 프로필로 만드는 것이 적절합니다.

**제목**
`[Tencent Cloud] 신규 계정 도메인 구매용 Registrant Profile 생성 및 휴대폰/이메일 인증 요청`

**요청 내용 (복사해서 사용)**
```text
Tencent Cloud 신규 계정에서 도메인 구매를 진행하려고 합니다.

Domains Console > Registrant Profile에서 아래 작업을 요청드립니다.
1. Mobile and Email Verification에서 업무용 이메일 및 휴대폰 번호 인증
2. Create Profile에서 Organization 유형의 Registrant Profile 생성
3. 생성한 프로필을 Default로 설정
4. 도메인 구매 시 해당 프로필을 선택할 수 있는지 확인

등록자 정보는 아래와 같습니다.
- Organization(법인명, 영문):
- 담당자 성/이름(영문):
- 업무용 이메일:
- 휴대폰 번호:
- 국가 / 도시:
- 영문 주소:
- 우편번호:

※ 휴대폰 인증번호는 보안상 작업 시점에 담당자에게 별도 전달하겠습니다.
※ 도메인 소유자는 법인으로 등록 부탁드립니다.
```

진행 순서는 다음과 같습니다.

1. Tencent Cloud **Domains Console** → **Registrant Profile**
2. **Mobile and Email Verification** 탭에서 업무용 이메일과 휴대폰 번호를 각각 인증
3. **Create Profile** → `Organization` 선택
4. 법인 영문명, 담당자 영문명, 영문 주소·도시·우편번호를 입력하고, 방금 인증한 이메일/휴대폰을 선택
5. 생성 후 **Set as Default**로 기본 프로필 지정
6. 도메인 구매 화면에서 이 프로필을 선택해 결제 진행

Tencent Cloud에서는 검증된 이메일과 휴대폰 번호만 등록자 프로필에 사용할 수 있습니다. 인증번호는 티켓 본문에 남기지 말고, 작업 중 담당자에게 안전한 채널로 전달하는 것이 좋습니다. [공식 모바일·이메일 인증 안내](https://intl.cloud.tencent.com/ko/document/product/242/42866), [공식 등록자 프로필 생성 안내](https://intl.cloud.tencent.com/document/product/242/45182)
