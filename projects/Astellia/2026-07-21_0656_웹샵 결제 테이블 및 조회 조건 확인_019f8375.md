### Assistant

원스토어 WebShop 결제 이력은 **Payment DB의 `paymentinfo` 테이블**에 저장됩니다.

WebShop 건을 구분하는 핵심 조건은 다음입니다.

```sql
SELECT *
FROM paymentinfo
WHERE uId = :uId
  AND charId = :serverGroupId  -- WebShop에서는 캐릭터 ID가 아닌 서버 그룹 ID
  AND osType = 6;
```

미지급 결제 건만 확인하려면:

```sql
AND isGiveItem = 0
```

- `osType = 6`: OneStore WebShop 결제
- `isGiveItem = 0`: 결제는 기록됐지만 아이템 지급 전
- `isGiveItem = 1`: 아이템 지급 완료
- `hiveTransactionId`: WebShop의 `purchaseId`; 유니크 키이므로 결제 건 식별/중복 확인에 가장 적합
- `hivePID`: 구매한 WebShop 상품 ID
- `regDate`, `price`, `buyCount`: 결제 시각·가격·수량

주의할 점은 WebShop 저장 시 `charId` 컬럼에 실제 캐릭터 ID 대신 `serviceServerId`(서버 그룹 ID)를 넣는다는 것입니다. 따라서 일반 결제처럼 캐릭터 ID로만 조회하면 누락될 수 있습니다.
