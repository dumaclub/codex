표시된 내용은 오류가 아니라, 설치 명령과 Product ID를 입력하지 않아 출력된 도움말입니다. 실행 파일만 호출하면 설치되지 않습니다.

먼저 현재 폴더에 설정 파일이 있는지 확인하세요.

```powershell
Get-ChildItem -Recurse -File |
    Where-Object Name -Match 'Settings|Config' |
    Select-Object FullName
```

보통 `Settings.json` 또는 `EasyAntiCheat_Settings.json` 안에 다음과 같은 값이 있습니다.

```json
{
  "productid": "32자리 Product ID",
  "sandboxid": "...",
  "deploymentid": "..."
}
```

파일 내용을 확인하려면:

```powershell
Get-Content .\Settings.json
```

Product ID를 확인한 뒤 설치하는 가장 편한 방법은 다음과 같습니다.

```powershell
.\EasyAntiCheat_EOS_Setup.exe verify-and-install "실제_Product_ID"
```

예:

```powershell
.\EasyAntiCheat_EOS_Setup.exe verify-and-install "95e760e6a6a447c28dc50db3e78d060f"
```

위 ID는 설명용 예시이므로, 실제 게임 설정 파일에 있는 `productid`를 사용해야 합니다. `verify-and-install`은 필요할 경우 관리자 권한 확인 창(UAC)을 자동으로 표시합니다.

관리자 PowerShell에서 직접 설치하려면:

```powershell
.\EasyAntiCheat_EOS_Setup.exe install "실제_Product_ID"
```

설치 여부 확인:

```powershell
.\EasyAntiCheat_EOS_Setup.exe verify-installation "실제_Product_ID"
$LASTEXITCODE
```

`$LASTEXITCODE`가 `0`이면 설치 확인에 성공한 것입니다.
