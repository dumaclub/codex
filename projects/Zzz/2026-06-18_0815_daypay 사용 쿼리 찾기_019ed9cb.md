네, 아래처럼 합치면 됩니다. 날짜만 바꾸면 현재 활성화된 모든 서버 그룹별 일 매출을 볼 수 있습니다.

```sql
SET @targetDate = '20260612';

SELECT
    sg.*,
    FORMAT(IFNULL(sales.pay, 0), 0) AS pay
FROM rasalas_global.server_group sg
LEFT JOIN (
    SELECT
        c.serverGroupId,
        SUM(p.price * p.buyCount) AS pay
    FROM rasalas_global.character_summary_info c
    INNER JOIN rasalas_payment.paymentinfo p
        ON p.charId = c.charId
    WHERE DATE_FORMAT(p.regDate, '%Y%m%d') = @targetDate
    GROUP BY c.serverGroupId
) sales
    ON sales.serverGroupId = sg.groupId
WHERE sg.state = 1
  AND sg.groupType = 2
ORDER BY sg.groupId;
```

결과는 `rasalas_global.server_group`의 활성 서버 그룹 정보 전체에 `pay` 컬럼이 붙어서 나옵니다.

매출이 없는 서버 그룹도 `0`으로 표시되게 `LEFT JOIN` + `IFNULL`을 사용했습니다.
