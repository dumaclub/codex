오류 코드 `0x80073CF6`은 **Claude 앱을 다른 드라이브에 복사한 뒤 Windows 앱 패키지를 새 위치에 등록하지 못했다**는 뜻입니다. 단순한 용량 부족 오류라기보다 Windows의 앱 패키지(MSIX/AppX) 등록 단계에서 실패한 것입니다. [Microsoft 오류 코드 설명](https://learn.microsoft.com/en-us/windows/win32/appxpkg/troubleshooting)

흔한 원인은 다음과 같습니다.

- C 드라이브 여유 공간이 너무 적어 이동 중 필요한 임시 작업 공간을 만들지 못함
- 대상 드라이브가 NTFS가 아니거나, 외장 드라이브 연결·권한·파일 시스템에 문제가 있음
- 대상 드라이브의 보호 폴더인 `WindowsApps` 권한 또는 기존 패키지 정보가 꼬임
- Claude가 백그라운드에서 실행 중이거나 파일이 사용 중
- Claude 앱 패키지 또는 Windows 앱 등록 정보 손상

먼저 다음 순서로 처리해 보세요.

1. C 드라이브에 최소 5~10GB 정도를 임시로 확보합니다.
2. Claude를 완전히 종료합니다. 시스템 트레이와 작업 관리자에서도 종료하세요.
3. PC를 재부팅한 후 Claude를 실행하지 않은 상태로 다시 이동합니다.
4. 대상 드라이브의 속성에서 파일 시스템이 `NTFS`인지 확인합니다.
5. `설정 → 앱 → 설치된 앱 → Claude → 고급 옵션`에서 **복구**가 있으면 실행한 후 다시 시도합니다. Windows에서도 앱 문제 시 복구 기능을 우선 사용하도록 안내합니다. [Windows 앱 복구 안내](https://support.microsoft.com/en-us/windows/apps/repair-apps-and-programs-in-windows)

그래도 실패하면 가장 확실한 방법은 다음과 같습니다.

1. `설정 → 시스템 → 저장소 → 고급 저장소 설정 → 새 콘텐츠가 저장되는 위치`
2. **새 앱 저장 위치**를 원하는 드라이브로 변경

### Claude 데스크톱 앱

설치 프로그램에서 경로를 직접 지정하는 방식은 지원되지 않습니다. 대신 Windows의 기본 앱 저장 위치를 바꾼 뒤 재설치해 볼 수 있습니다.

1. `설정 → 시스템 → 저장소`
2. `고급 저장소 설정 → 새 콘텐츠가 저장되는 위치`
3. **새 앱 저장 위치**를 `D:`로 변경
4. Claude 제거
5. PC 재부팅
6. Microsoft Store에서 Claude 재설치

Microsoft도 이 메뉴를 통해 새 앱·콘텐츠의 저장 드라이브를 변경하도록 안내합니다. [Microsoft 저장 위치 변경 안내](https://support.microsoft.com/en-US/Windows/Experience/Storage-FileManagement/free-up-drive-space-in-windows)

다만 앞서 `0x80073CF6` 오류가 발생했으므로 다음 조건을 먼저 확인해야 합니다.

- D 드라이브가 `NTFS` 형식인지 확인
- D 드라이브에 충분한 공간이 있는지 확인
- C 드라이브에도 설치 임시 공간으로 5~10GB 정도 확보
- D 드라이브의 `WindowsApps` 폴더를 직접 수정하지 않기

위 방법으로 재설치해도 C에 설치된다면 해당 Claude 패키지가 시스템 드라이브 설치를 강제하는 경우이며, 심볼릭 링크 등으로 강제 이동하는 방법은 업데이트와 앱 실행을 망가뜨릴 수 있어 권장하지 않습니다.

### 실제 Claude Code CLI라면

Claude Code를 `npm`으로 설치한 경우에는 D 드라이브로 설치 위치를 지정할 수 있습니다. 기존 버전을 먼저 제거한 다음 PowerShell에서 실행합니다.

```powershell
npm uninstall -g @anthropic-ai/claude-code

New-Item -ItemType Directory -Path "D:\npm-global" -Force
npm config set prefix "D:\npm-global"

npm install -g @anthropic-ai/claude-code
```

그런 다음 Windows 환경 변수의 사용자 `Path`에 아래 경로를 추가하고 터미널을 다시 열어야 합니다.

```text
D:\npm-global
```

확인 명령은 다음과 같습니다.

```powershell
npm config get prefix
where.exe claude
claude doctor
```

Claude Code의 공식 설치 명령은 `npm install -g @anthropic-ai/claude-code`이며, npm은 Windows에서 전역 패키지를 지정된 `prefix` 아래에 설치합니다. [Claude Code 설치 안내](https://docs.anthropic.com/en/docs/claude-code/getting-started), [npm 설치 위치 설명](https://docs.npmjs.com/files/folders.html/)

즉, **스크린샷의 Claude 데스크톱 앱은 Windows 저장 위치 변경 후 재설치**, **터미널용 Claude Code는 npm `prefix`를 D 드라이브로 변경**하는 것이 맞습니다.
